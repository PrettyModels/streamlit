# PrettyModels AI - Investment Intelligence Research Lab

A Streamlit site for [PrettyModels AI](https://prettymodels.ai/), positioned as an applied AI investment research lab for public-market allocation.

The site presents:

- AI-driven signal research for public equities
- Marylin as a live research case study
- An interactive signal watchlist for inspecting model outputs
- Clear handoff to [tausch.capital](https://tausch.capital/) for asset-management and Wikifolio-facing material

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://prettymodels.ai/)

### How to run it on your own machine

1. Install the requirements

   ```
   $ pip install -r requirements.txt
   ```

2. Run the app

   ```
   $ streamlit run streamlit_app.py
   ```
